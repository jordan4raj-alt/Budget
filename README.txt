BUILD THE APK
1. Install Android Studio on a computer.
2. Open the folder named BudgetAssessment (the folder containing settings.gradle).
3. Allow Android Studio to sync Gradle and install Android SDK Platform 35 if prompted.
4. Choose Build > Build Bundle(s) / APK(s) > Build APK(s).
5. Android Studio will create the APK under:
   app/build/outputs/apk/debug/app-debug.apk
6. Transfer that APK to your OnePlus Nord CE 4 and install it. You may need to allow
   installation from the file manager/browser you use.

This deliverable is the complete Android Studio project source, not a compiled APK.
A local Android SDK/Gradle build environment is not available in this workspace,
so a verified installable APK could not be compiled here.
